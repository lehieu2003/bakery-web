## Key Lessons Learned

1. Treat status synchronization as a required completion step.
- Story markdown status, sprint-status, and review findings should be updated in the same closeout pass.

2. Preserve historical state unless transition intent is explicit.
- `publishedAt` behavior in blog/content flows showed the need to separate "edit metadata" from "state transition".

3. Make multi-write mutations transactional by default.
- Post/tag update path confirmed partial-write risk when not wrapped in a single transaction.

4. Keep validation strict at boundary, tolerant in orchestration.
- Route boundaries should reject malformed payloads early; service/hooks should remain contract-stable.
