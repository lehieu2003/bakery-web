## Key Lessons Learned

1. Sequence matters for governance work.
- Delivering investigation -> audit -> RBAC -> contract consistency reduced rework and avoided policy churn.

2. Compatibility guards are essential for contract-safe evolution.
- Adding explicit contract compatibility tests prevented regressions while hardening response shapes.

3. Centralized primitives reduce boundary defects.
- Shared RBAC and shared envelope helpers lowered route-level divergence and review findings.

4. “Done” needs dual confirmation.
- Story file state and sprint status must be checked together to avoid reporting confusion.
